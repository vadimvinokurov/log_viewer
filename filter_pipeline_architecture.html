1. Общая модель

FilterPipeline — stateful-объект, владеющий всем состоянием фильтрации. Не хранит сами данные логов — только правила и закэшированные маски. Принимает LogStore как аргумент в каждом методе, читает из него SoA-массивы и буфер, пишет обратно filtered_indices и level_button_counts.

Три независимых вида правил:

Filters

Текстовые правила. Сужают видимость. Множественные фильтры комбинируются через OR.

AND с категориями/уровнями

Pins

Правила закрепления. Обходят ВСЕ фильтры. Множественные пины через OR.

OR после combined

Highlights

Не влияют на видимость. Только окрашивают ячейки. Хранятся здесь для единообразия.

Вне apply()

Плюс два «столбовых» фильтра — категории и уровни — которые не хранят маски, а вычисляются на лету через np.isin().

2. Структуры данных

class FilterPipeline:
    # --- Текстовые фильтры ---
    filters:          list[Filter]       # [Filter("error", PLAIN), Filter("warn|crit", REGEX), ...]
    filter_enabled:   list[bool]         # [True, True, ...]  — 1:1 с filters
    _filter_masks:    list[np.ndarray]   # [array([F,F,T,T,F,...]), ...]  — bool mask, len=n

    # --- Pins ---
    pinned_rules:     list[Filter]       # те же Filter, но используются как OR в конце
    pinned_enabled:   list[bool]
    _pin_masks:       list[np.ndarray]   # закэшированные булевы маски

    # --- Подсветка ---
    highlights:       list[Highlight]    # [Highlight("timeout", PLAIN, "#ff6600"), ...]
    highlight_enabled:list[bool]
    _highlight_color_index: int          # round-robin по HIGHLIGHT_PALETTE

    # --- Столбовые фильтры ---
    disabled_levels:    set[int]         # {2, 4}  — ID отключённых уровней
    disabled_categories:set[int]         # {1, 5}  — ID отключённых категорий

    # --- Оптимизация ---
    _term_cache:      dict[str, np.ndarray]  # "error" → bool mask (разделяется между queries)

Invariants

  • len(filters) == len(filter_enabled) == len(_filter_masks) — всегда
  • Каждая маска в _filter_masks — np.ndarray(bool) длины store.n
  • Маска вычисляется один раз при add_filter(), кэшируется, пересчитывается только при recompute_masks() (после загрузки нового файла)
  • disabled_levels и disabled_categories — множества ID, не маски. Маска вычисляется в apply() каждый раз.

3. _compute_mask: булевы маски одного фильтра

Центральный алгоритм. Принимает один Filter, возвращает np.ndarray(bool) длины n. Используется для фильтров, пинов и поиска.

def _compute_mask(self, store: LogStore, filt: Filter) -> np.ndarray:
    n = store.n
    mask = np.zeros(n, dtype=bool)          # всё False

    if filt.mode == SearchMode.LINE_NUMBER:
        idx = int(filt.pattern) - 1          # 1-based → 0-based
        if 0 <= idx < n:
            mask[idx] = True
        return mask

    if filt.mode in (PLAIN, REGEX):
        # ... поиск по буферу (см. раздел 4) ...
    else:  # SIMPLE
        # ... AST + term masks (см. раздел 5) ...

    return mask

Общая схема для PLAIN/REGEX

┌─────────────┐ ┌──────────────────┐ ┌───────────────────────┐ │ buf_lower │────▶│ re.finditer() │────▶│ positions: [42, 187] │ │ (bytes) │ │ по всему буферу │ │ byte offsets in buf │ └─────────────┘ └──────────────────┘ └───────────┬───────────┘ │ ┌────────────▼────────────┐ │ np.searchsorted( │ │ line_starts, │ │ positions, │ │ side="right") - 1 │ │ │ │ byte offset → line idx │ │ O(log n) per position │ └────────────┬────────────┘ │ ┌────────────▼────────────┐ │ mask[line_indices] │ │ = True │ │ │ │ [F,F,F,T,F,...,T,...] │ └─────────────────────────┘

Ключевой инсайт: поиск идёт по сырому байтовому буферу, а не по отдельным строкам. Позиции совпадений маппятся обратно на номера строк через бинарный поиск по массиву line_starts.

4. PLAIN и REGEX: поиск в байтовом буфере

Оба режима работают одинаково — отличаются только подготовкой паттерна. Оба работают на _buf_lower (lowercase-версия буфера).

PLAIN

# Паттерн экранируется → literal поиск
pattern = re.escape(filt.pattern.lower()).encode("utf-8")
combined = re.compile(pattern)

# Поиск по всему буферу за один вызов
positions = np.array(
    [m.start() for m in combined.finditer(store._buf_lower)],
    dtype=np.int64,
)

REGEX

# Паттерн as-is, только lower()
combined = re.compile(filt.pattern.lower().encode("utf-8"))

# Тот же finditer по _buf_lower
positions = np.array(
    [m.start() for m in combined.finditer(store._buf_lower)],
    dtype=np.int64,
)
Почему lower(), а не IGNORECASE: В комментарии кода: «Python has no lookup tables for bytes IGNORECASE regex — ~50x slower». Поэтому буфер заранее конвертируется в lowercase, а regex работает case-sensitive на lowercase-данных.

Маппинг позиций → строки

Общий для PLAIN, REGEX и SIMPLE-термов:

# line_starts = [0, 42, 85, 130, ...]  — оффсет начала каждой строки в _buf
# position = 100                         — найдено совпадение в буфере

line_indices = np.searchsorted(store.line_starts, positions, side="right") - 1

# searchsorted([0, 42, 85, 130], 100, side="right") = 3
# 3 - 1 = 2  →  строка #2 содержит совпадение

valid = (line_indices >= 0) & (line_indices < n)
mask[line_indices[valid]] = True

side="right" — означает «индекс первого элемента > value». Вычитаем 1 — получаем индекс строки, внутри которой находится позиция.

Сложность: re.finditer() — O(|buf|) на каждый паттерн. np.searchsorted() — O(k · log n), где k — количество совпадений. Для типичного фильтра k << n.

5. SIMPLE: AST + векторизованные маски

Запрос парсится в AST через simple_query.parse_query(). AST декомпозируется на уникальные термы, каждый терм сканируется по буферу отдельно, затем маски комбинируются через numpy-операции.

Пример

# Запрос:
("error" OR "timeout") AND NOT "retry"

# AST:
AndNode(
    left=OrNode(
        left=TermNode("error"),
        right=TermNode("timeout")
    ),
    right=NotNode(
        child=TermNode("retry")
    )
)

Алгоритм в _compute_mask

# 1. Парсинг
ast = parse_query(filt.pattern)

# 2. Извлечение уникальных термов
unique_terms = list(set(ast.collect_terms()))   # ["error", "timeout", "retry"]

# 3. Для каждого терма — буферный поиск → bool mask
term_masks: dict[str, np.ndarray] = {}
for term in unique_terms:
    if term in self._term_cache:       # кэш!
        term_masks[term] = self._term_cache[term]
        continue
    tmask = np.zeros(n, dtype=bool)
    pattern = re.escape(term.lower()).encode("utf-8")
    positions = [m.start() for m in re.compile(pattern).finditer(buf_lower)]
    if positions:
        line_indices = np.searchsorted(line_starts, positions, side="right") - 1
        tmask[line_indices] = True
    self._term_cache[term] = tmask
    term_masks[term] = tmask

# 4. AST вычисляет финальную маску через numpy
mask = ast.eval_masks(term_masks, n)

eval_masks() — векторизованная рекурсия

Каждая AST-нода реализует eval_masks():

Нодаeval_masksNumpy
TermNode("error") Возвращает готовую маску из словаря term_masks["error"]
AndNode(left, right) Рекурсия на оба поддерева, побитовое AND left.eval() & right.eval()
OrNode(left, right) Рекурсия, побитовое OR left.eval() | right.eval()
NotNode(child) Рекурсия, побитовое NOT ~child.eval()

Для примера ("error" OR "timeout") AND NOT "retry":

# step 1: term_masks["error"]    = [F, T, F, F, T, F, ...]   строки с "error"
# step 2: term_masks["timeout"]  = [F, F, T, F, F, F, ...]   строки с "timeout"
# step 3: term_masks["retry"]    = [F, F, T, F, F, T, ...]   строки с "retry"

or_mask   = term_masks["error"] | term_masks["timeout"]
#            [F, T, T, F, T, F, ...]

not_mask  = ~term_masks["retry"]
#            [T, T, F, T, T, F, ...]

result    = or_mask & not_mask
#            [F, T, F, F, T, F, ...]
#  строка 1: error, но не retry  ✓
#  строка 2: timeout, но retry тоже → вырезана  ✓
#  строка 4: error, но не retry  ✓

Парсер

_Parser — recursive descent. Грамматика:

or_expr    → and_expr ("OR" and_expr)*
and_expr   → not_expr ("AND" not_expr)*
not_expr   → "NOT" not_expr | primary
primary    → "(" or_expr ")" | STRING

# STRING: '"' ... '"'
# Приоритет: NOT > AND > OR

Результат кэшируется через @lru_cache(256) на parse_query() — повторный запрос с той же строкой не парсится заново.

6. apply(): сборка финальной маски

Вызывается после любого изменения состояния: добавление/удаление фильтра, toggle уровня/категории, pin/unpin. Пересчитывает store.filtered_indices.

Формула

filtered_indices = np.where( (cat_mask & level_mask & text_mask) # combined — сужение | pin_mask # расширение )[0]

Алгоритм по шагам

def apply(self, store: LogStore) -> None:
    n = store.n

    # --- Fast path: ничего не фильтруется ---
    if not (filters or disabled_levels or disabled_categories or pins):
        store.filtered_indices = np.arange(n, dtype=uint32)
        return

    # --- 1. Category mask: True = категория включена ---
    if disabled_categories:
        enabled_cats = np.array(
            [i for i in range(len(cat_names)) if i not in disabled_cats],
            dtype=uint16,
        )
        cat_mask = np.isin(store.category_ids, enabled_cats)
    else:
        cat_mask = np.ones(n, dtype=bool)   # все True

    # --- 2. Level mask: True = уровень включён ---
    if disabled_levels:
        enabled_lvls = np.array([...], dtype=uint8)
        level_mask = np.isin(store.levels, enabled_lvls)
    else:
        level_mask = np.ones(n, dtype=bool)

    # --- 3. Text filter mask: OR всех активных фильтров ---
    if has_text_filters:
        active_masks = [m for m, e in zip(_filter_masks, filter_enabled) if e]
        text_mask = np.zeros(n, dtype=bool)
        for m in active_masks:
            text_mask |= m                   # OR!
    else:
        text_mask = np.ones(n, dtype=bool)

    # --- 4. Combined: AND трёх масок ---
    combined = cat_mask & level_mask & text_mask

    # --- 5. Pins: OR в конец ---
    if has_pins:
        pin_mask = np.zeros(n, dtype=bool)
        for m in active_pin_masks:
            pin_mask |= m
        combined = combined | pin_mask       # обходит всё

    # --- 6. Результат ---
    store.filtered_indices = np.where(combined)[0].astype(uint32)
    store._count_visible_levels()

Визуализация для файла из 6 строк

# Файл:
#   0: [INFO]  app/main    Starting
#   1: [ERROR] app/net      Connection timeout
#   2: [WARN]  app/net      Retrying
#   3: [ERROR] system/io    Disk full
#   4: [DEBUG] app/main     Cache miss
#   5: [INFO]  system/io    Cleanup done

# Фильтр: "timeout" (PLAIN)
text_mask = [F, T, F, F, F, F]

# Категория "system/io" отключена
cat_mask  = [T, T, T, F, T, F]

# Level DEBUG отключен
level_mask= [T, T, T, T, F, T]

# Pin: "disk" (PLAIN)
pin_mask  = [F, F, F, T, F, F]

combined  = cat_mask & level_mask & text_mask
          = [F, T, F, F, F, F]

result    = combined | pin_mask
          = [F, T, F, T, F, F]
#            ↑ timeout, cat=app/net, level=ERROR ✓
#                  ↑ PIN! обходит cat и text     ✓

filtered_indices = [1, 3]

Подсчёт level_button_counts

Отдельно от финальной маски. Кнопки уровней показывают количество строк по категории и тексту, но без учёта toggle самих уровней. Это нужно чтобы пользователь видел «если я включу WARN — там 15 строк».

# cat_text_mask — без level toggle
cat_text_mask = cat_mask & text_mask if has_text_filters else cat_mask

cat_indices = np.where(cat_text_mask)[0]
cat_levels  = store.levels[cat_indices]
counts      = np.bincount(cat_levels, minlength=len(_LEVEL_LIST))

store.level_button_counts = {
    _LEVEL_LIST[i]: int(counts[i])
    for i in range(len(_LEVEL_LIST))
    if counts[i] > 0
}

7. Pinned lines: обход фильтров

Pins хранятся как Filter объекты — тот же тип, те же режимы. Маска вычисляется через тот же _compute_mask().

def add_pin(self, store: LogStore, filt: Filter) -> None:
    self.pinned_rules.append(filt)
    self.pinned_enabled.append(True)
    self._pin_masks.append(self._compute_mask(store, filt))   # тот же метод
    self.apply(store)

# В apply():
#   combined = cat & level & text     # фильтры сужают
#   combined = combined | pin_mask     # пины расширяют

Семантика

  • Строка закрепляется по правилу (pattern + mode), а не по номеру
  • Если файл перезагружен — пин-правило пересчитывает маску (recompute_masks())
  • Пины комбинируются через OR — закреплено хотя бы по одному правилу → видно
  • Пин обходит ВСЕ фильтры: категории, уровни, текст

8. Категории: дерево и маски

Отключение

def disable_category(self, store, path: str) -> None:
    for node in self._match_categories(store, path):
        self._set_enabled_recursive(store, node, False)
    self.apply(store)

def _set_enabled_recursive(self, store, node, enabled):
    node.enabled = enabled
    if node.full_path:
        cat_id = store._category_name_to_id.get(node.full_path)
        if cat_id is not None:
            if enabled:
                self.disabled_categories.discard(cat_id)
            else:
                self.disabled_categories.add(cat_id)
    for child in node.children.values():
        self._set_enabled_recursive(store, child, enabled)

Отключение родителя отключает всех потомков рекурсивно. disabled_categories — плоский set ID листовых узлов.

Маска в apply()

# disabled_categories = {1, 5}
# category_ids = [0, 1, 0, 5, 0, 2]

enabled_cats = np.array(
    [i for i in range(len(cat_names)) if i not in disabled_cats],
    dtype=uint16,
)
cat_mask = np.isin(store.category_ids, enabled_cats)
# [T, F, T, F, T, T]  — строки с cat_id 1 и 5 вырезаны

Wildcard-матч

_match_categories() поддерживает * в пути:

# :catd app/*
regex = re.compile(".*".join(re.escape(p) for p in "app/*".split("*")))
# → re.compile(r"app/.*")
# Матчит: "app/main", "app/net/http", "app/net/ws"

9. Уровни: toggle и подсчёт

Аналогично категориям, но плоско — без дерева.

def toggle_level(self, store, level: LogLevel):
    level_id = _LEVEL_LIST.index(level)   # INFO=0, ERROR=3, ...
    if level_id in self.disabled_levels:
        self.disabled_levels.discard(level_id)   # включить
    else:
        self.disabled_levels.add(level_id)       # выключить
    self.apply(store)

В apply():

# disabled_levels = {4}  (DEBUG)
# levels = [0, 3, 2, 3, 4, 0]

level_mask = np.isin(store.levels, enabled_levels)

10. Highlights

Highlights не влияют на filtered_indices — они только хранят правила для подсветки. Таблица читает их при рендеринге ячеек.

def add_highlight(self, h: Highlight):
    # Авто-назначение цвета из палитры (round-robin)
    h.color = HIGHLIGHT_PALETTE[self._highlight_color_index % len(HIGHLIGHT_PALETTE)]
    self._highlight_color_index += 1
    self.highlights.append(h)
    self.highlight_enabled.append(True)

Highlights не вызывают apply() — они не меняют видимость. GUI перечитывает highlights при каждой перерисовке.

11. Термовый кэш

_term_cache: dict[str, np.ndarray] — кэш масок для уникальных термов из SIMPLE-запросов.

# Запрос 1: "error" AND "timeout"
#   → сканирует "error" и "timeout", кэширует обе маски

# Запрос 2: "error" OR "warning"
#   → "error" берётся из кэша, сканируется только "warning"

# В _compute_mask:
for term in unique_terms:
    if term in self._term_cache:
        if len(cached) == n:           # защита от stale после перезагрузки
            term_masks[term] = cached
            continue
    # ... сканирование буфера ...
    self._term_cache[term] = tmask

Сбрасывается через invalidate_cache(), вызывается из LogStore.load_bytes().

Зачем: SIMPLE-запросы часто переиспользуют термы. Без кэша каждый запрос заново сканировал бы весь буфер. С кэшем — только новые термы.

12. Полный пример

Файл из 5 строк, пользователь выполняет серию действий:

# Лог-файл (5 строк, KSIVA-формат):
#
#   line 0: 2024-01-01T10:00:00 app/main [LOG_INFO]  Starting
#   line 1: 2024-01-01T10:00:01 app/net  [LOG_ERROR] Connection timeout
#   line 2: 2024-01-01T10:00:02 app/net  [LOG_WARN]  Retrying
#   line 3: 2024-01-01T10:00:03 sys/io   [LOG_ERROR] Disk full
#   line 4: 2024-01-01T10:00:04 app/main [LOG_DEBUG] Cache miss

# === SoA после парсинга ===
category_ids = [0, 1, 1, 2, 0]    # 0=app/main, 1=app/net, 2=sys/io
levels       = [0, 3, 2, 3, 4]    # 0=INFO, 2=WARN, 3=ERROR, 4=DEBUG

# ========================================
# Действие 1: :f "timeout"  (PLAIN filter)
# ========================================
# _compute_mask("timeout", PLAIN)
#   → finditer в buf_lower: position=63 (внутри строки 1)
#   → searchsorted(line_starts, 63) - 1 = 1
#   → mask = [F, T, F, F, F]

filter_mask_1 = [F, T, F, F, F]

# apply():
#   cat_mask   = [T,T,T,T,T]  (ничего не отключено)
#   level_mask = [T,T,T,T,T]  (ничего не отключено)
#   text_mask  = [F,T,F,F,F]  (filter_mask_1, OR всех фильтров)
#   combined   = [T,T,T,T,T] & [T,T,T,T,T] & [F,T,F,F,F]
#             = [F,T,F,F,F]
#   pins       = нет
#   result     = [F,T,F,F,F]

filtered_indices = [1]
# ✓ Видна только строка 1: "Connection timeout"


# ========================================
# Действие 2: :f "disk"  (добавляем второй фильтр)
# ========================================
filter_mask_2 = [F, F, F, T, F]

# apply():
#   text_mask = filter_mask_1 | filter_mask_2
#            = [F,T,F,F,F] | [F,F,F,T,F]
#            = [F,T,F,T,F]
#   combined  = [T,T,T,T,T] & [T,T,T,T,T] & [F,T,F,T,F]
#            = [F,T,F,T,F]

filtered_indices = [1, 3]
# ✓ Фильтры комбинируются через OR: "timeout" OR "disk"


# ========================================
# Действие 3: :catd sys/io  (отключаем категорию)
# ========================================
disabled_categories = {2}   # sys/io

# apply():
