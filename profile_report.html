Вывод

Векторизованный парсер дал реальное ускорение.

  • Убран парсинг timestamp — вместо перевода каждой строки в ms, хранятся сырые байтовые спаны. Декодирование только для видимых строк (~50).
  • np.where() для поиска переносов строк — SIMD-level сканирование через C-код numpy вместо Python while-цикла.
  • Ручное сканирование байт вместо split()/find() — прямое сравнение байт (line[pos] == 32) быстрее чем split(None, 4) + decode + dict lookup.
  • dict[bytes, int] для категорий — нет нужды декодировать bytes→str для каждой категории, только для новых.

Оставшийся bottleneck: цикл Python по 6.4M строк всё ещё занимает ~19s под профайлером (~10s без). Для дальнейшего ускорения нужен C-extension или Cython.
